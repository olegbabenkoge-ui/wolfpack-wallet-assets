# wolfpack-wallet-assets

Публичные картинки для карт лояльности Wolfpack в Google Wallet и Apple Wallet.
Репозиторий публичный намеренно: Google скачивает изображения карты по прямой https-ссылке.

Здесь только графика. Ключи, сертификаты и код — в приватном репозитории проекта.

Файлы генерируются скриптом `scripts/build-brand.js` основного проекта.
